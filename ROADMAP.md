# Roadmap

## 1.0 — first public release
- Inventory (zero-AI CLI) for Tailwind v4 + shadcn/cva projects: tokens on 5 axes, 11 form components, screen attribution, sibling checks.
- Single-file HTML report with real-size specimens and a curation UI.
- `/design-polish` skill: diagnosis, proposal cards, curation hand-off, one-commit-per-card apply, automatic re-count, DESIGN-TOKENS.md + agent pointer.
- `design-polish check` baseline guard for CI.

## 1.1
- Tailwind v3 and CSS Modules adapters.
- "Barely visible" and "visible" change cards with per-item approval.
- Opt-in advanced card: extract a repeated inline pattern into a component.
- Dark-mode specimen toggle, focus-state tab, batch questions for ambiguous sites, DTCG token export card.

## 1.2
- Measured mode: when the app is running, verify computed styles in a real browser.
- Run history chart, description tuning with trigger evals, bundled parser for JS-only projects.

## Not planned
- Redesigns, aesthetic scoring, UX copy, Figma sync, Storybook generation, full accessibility audits.
